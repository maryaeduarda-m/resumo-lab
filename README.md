# resumo-lab
Este repositório contém o resumo das lições aprendidas durante o desenvolvimento do lab na DIO

Focado no entendimento prático da computação em nuvem. A finaliade é mostrar, de forma simples e aplicada, como os serviços em nuvem podem tornar sistemas mais eficientes, escaláveis e adaptáveis às necessidades do usuário. Através de exemplos práticos, demonstra como migrar aplicações para a nuvem, otimizar recursos e utilizar serviços cloud para obter melhores resultados com menor custo operacional.
