# resumo-lab
Este repositório contém o resumo das lições aprendidas durante o desenvolvimento do lab na DIO

Este projeto explora como a computação em nuvem pode ser aplicada para melhorar a eficiência, escalabilidade e flexibilidade. Através de exemplos práticos, demonstra como migrar aplicações para a nuvem, otimizar recursos e utilizar serviços cloud para obter melhores resultados com menor custo operacional.
